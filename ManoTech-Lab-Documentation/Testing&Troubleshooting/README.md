# Troubleshooting Center

## Overview

This section contains documented troubleshooting scenarios encountered during the deployment and configuration of the ManoTech Enterprise Windows Server Lab.

Each document describes the problem, symptoms, root cause, resolution steps, and validation process.

---

## Troubleshooting Categories

| Category | Description |
|----------|-------------|
| VMware | Virtual machine networking and virtualization issues |
| Active Directory | Domain join and authentication problems |
| DNS & DHCP | Name resolution and IP assignment issues |
| Group Policy | Policy processing and configuration problems |
| File Server | Permissions and access control issues |
| AD CS | Certificate enrollment and PKI issues |
| WSUS | Update management issues |
| PowerShell | Automation script issues |

---

## Purpose

The goal of this documentation is to demonstrate troubleshooting methodology and problem-solving skills during enterprise infrastructure deployment.
